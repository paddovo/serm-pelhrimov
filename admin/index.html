Jak přidat nové fotografie do galerie

Web funguje jako čistý statický web bez databázového serveru. Správa fotografií probíhá prostřednictvím GitHub repository:

  1. Nahraj fotografii do repository:

    Ulož nový obrázek (např. images/serm-01.jpg) do složky images/ na GitHubu.

  2. Aktualizuj datový soubor galerie:

    Otevři soubor data/gallery.json a přidej nový záznam:

    {
  "id": 7,
  "title": "Název fotky",
  "caption": "Popis fotografie...",
  "category": "Tréninky",
  "image": "images/serm-01.jpg",
  "alt": "Popis obrázku"
}
  3. Potvrď změny (Commit):

    Po uložení změn Vercel během několika sekund automaticky nasadí novou verzi galerie na doménu sermpelhrimov.cz.
